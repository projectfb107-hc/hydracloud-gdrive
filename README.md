# Hydra GDrive

A free, non-commercial build of [Hydra Launcher](https://github.com/hydralauncher/hydra) (MIT) that can keep your game saves in **your own** Google Drive.

- **Download:** [latest release](https://github.com/projectfb107-hc/hydracloud-gdrive/releases/latest) (Linux x86_64 RPM)
- **Setup:** Settings → Integrations → Google Drive → Connect. A Hydra account (free is fine) is still required.
- [Privacy Policy](https://projectfb107-hc.github.io/hydracloud-gdrive/privacy.html) · [Terms of Service](https://projectfb107-hc.github.io/hydracloud-gdrive/terms.html)
